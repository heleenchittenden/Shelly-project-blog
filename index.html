01 / The problem

Scheduling physical spaces shouldn't be a puzzle.

Sporting facilities need to coordinate equipment across multiple classes and activities. When schedules are managed on paper or across disconnected tools, finding available equipment and avoiding booking conflicts takes extra effort.

The idea behind Shelly

Give facility staff a clear, visual way to understand their space, see equipment availability and coordinate bookings with class schedules.

02 / The solution

One facility. Two ways to plan.

Shelly connects the physical layout of a facility with the schedules that determine how its equipment is used.

01

Map the facility

In setup mode, arrange equipment as blocks on a visual map of the facility. Create a spatial representation of the equipment that needs to be scheduled.

02

Explore equipment schedules

In booking mode, select an equipment block on the map to view its schedule and make bookings for specific classes and time slots.

03

Plan from the class perspective

View an individual class's schedule and book the equipment it needs, keeping the activity and its requirements at the centre of the workflow.

04

Check availability before booking

When selecting equipment for a requested time slot, see whether it is available. This helps staff identify conflicts before committing to a booking.

05 / Under the hood

A practical web application.

Shelly uses a JavaScript frontend and a Node.js backend. Application records are currently stored as JSON files.

Frontend

Built with JavaScript and Vite, providing the interface for facility setup, schedules and equipment bookings.

Backend and data

A Node.js backend supports the application, with records persisted in JSON files.
